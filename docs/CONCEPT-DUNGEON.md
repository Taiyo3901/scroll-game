# コンセプト案：ウェブの迷宮（ダンジョン探索風）

`SPEC.md` の「鉱石を掘る」を置き換える案。内容がまとまったら `SPEC.md` の4章、5章、6章に反映する。ゲーム名は仮称のまま。

## 0. 方針

- 普段の作業や閲覧に「プラスα」するもの。**ユーザーが考えること、管理することを増やさない。**
- 油・松明・バッグ・帰還などの管理要素はなくす。
- 遊び方は「いつもどおり読む」だけ。下にスクロールすると階層を降り、止まると、いまのサイトにまつわる品が見つかって図鑑に入る。

## 1. ゲームの流れ

1. 下にスクロールすると、迷宮を降りる（深度が増える）。
2. スクロールを止めて**1秒後**から右端のゲージがたまり、**約4秒**で品が見つかる。
3. 見つけた品は**そのまま図鑑に登録**され、ポイントが入る。
4. 以上。操作も管理もない。

なくすもの：ランタンの油／バッグ／地上に戻る操作／自動帰還／強制帰還／探検中と地上の区別。
残すもの：1日の探索回数の上限（ランキングの不正値を見分ける基準。普通に遊ぶ分には意識しなくてよい数にする）、ゲージ、右端の帯。

## 3. 階層

深度で階層が決まる。階層は「景色」と「レア度の出やすさ」を変える。

| 階層 | 深度（仮） | 帯の色 | 雰囲気 |
|---|---|---|---|
| 第1層 はじまりの洞窟 | 0〜50m | 茶 | 土と木の根 |
| 第2層 地下水路 | 50〜150m | 黄土 | 湿った石組みと水音 |
| 第3層 古の坑道 | 150〜400m | 緑灰 | 朽ちた木枠とトロッコの跡 |
| 第4層 水晶の回廊 | 400〜800m | 青緑 | 壁一面の水晶 |
| 第5層 溶岩の間 | 800〜1500m | 暗い青灰 | 赤い光と熱気 |
| 第6層 奈落の底 | 1500m〜 | 紫 | 光の届かない最深部 |

- 深いほど★2・★3の重みが上がる（基準は★1:70/★2:25/★3:5）。
- 各階層に1つ、その階層だけで出る「秘宝」を置く。系統に関係なく、約3%で出る。

## 4. 部屋（サイトの系統）

閲覧中のサイトの系統で、見つかる品が変わる。系統は RPG によく出てくる施設の名前にして、名前を見ればどんなサイトか分かるようにした。

| 部屋 | どんなサイト | ID |
|---|---|---|
| 劇場 | 動画、配信 | video |
| 酒場 | SNS、掲示板、コミュニティ | sns |
| 情報屋 | ニュース、ブログ、読み物 | news |
| 書庫 | 辞書、百科事典、学習、技術文書 | study |
| 道具屋 | 買い物、フリマ | shop |
| 工房 | コード、開発者向け | dev |
| 闘技場 | ゲーム、攻略、対戦 | game |
| 音楽堂 | 音楽、楽譜、演奏 | music |
| 宿場町 | 地図、旅行、乗換案内 | travel |
| ギルド | メール、カレンダー、オフィス系（仕事・連絡） | work |
| 未踏の地 | 上のどれにも当てはまらないサイト | other |

- 判定は、閲覧中のサイトのホスト名を content script の中だけで同梱の辞書と照合して行う。service worker に送るのは部屋のIDだけで、ホスト名・URL・タイトルは送らず、保存もしない。
- 辞書にないサイトは「未踏の地」。
- **機微なサイトは辞書に載せず、「未踏の地」にする**（成人向け、医療・健康、金融・銀行、宗教・政治など）。ローカルホスト、社内ホスト、IPアドレス直指定も「未踏の地」。
- 辞書の元データは私が作り、割り当てを確認してもらう。

## 6. 職業

見つけた品の部屋の割合から、職業の称号が付く。ある部屋が4割以上ならその部屋の職業。どの部屋も3割未満なら「勇者」（万能）。週ごとと全期間の両方を出す。**見るだけで、操作や管理は要らない。**

職業は、ドラゴンクエストやファイナルファンタジーなど、RPG で定番の職業から選んだ。部屋の施設と結び付けやすいものにしてある。

## 7. 遊び心の機能

- **職業診断**：上の職業。図鑑ページの上部に出す。
- **部屋の分布グラフ**：図鑑に帯グラフを置く。今週と全期間。
- **部屋ごとの発見率**：「劇場 4/6」のように出す。
- **記録**：日ごと・週ごとの探索回数、ポイント、スクロール距離に、部屋別の探索回数を足す。CSVにも出す。
- **フレンド**：フレンドの図鑑、職業、部屋の分布、飾り棚（3つまで）を見られる。図鑑比べは部屋ごとに「自分だけ／相手だけ／両方」を色分けする。
- **ランキング**：指標は「今週のポイント合計」（★1=1点、★2=3点、★3=10点）。あわせて、図鑑の発見数と、今週の発見数を出す。部屋や職業では順位を付けない。

## 8. プライバシーの扱い

- ホスト名は content script の中で使うだけで、保存も送信もしない。外に出るのは、発見品の所持数と、その部屋から分かる傾向まで。
- フレンドへの公開は**初期設定でオフ**。オンにしたときだけ、図鑑・職業・部屋の分布が見える。
- 部屋ごとに「フレンドには見せない」を選べる。見せない部屋の発見品は、フレンドからは「？」で伏せる。
- 設定画面に「フレンドにどう見えるか」のプレビューを出す。
- 初回の説明画面に、「サイトの種類だけを記録し、サイトそのものは記録しない」と明記する。

## 9. 実装への影響

- 削除：油、バッグ、帰還（手動・自動・強制）、探検中と地上の区別、バッジの状態色、ポップアップの「地上に戻る」、`chrome.alarms` の1分ごとの処理（自動帰還と油の回復）。`chrome.idle` も不要になる。
- データ：`strata.json`（階層）、`genres.json`（部屋と辞書）、`items.json`（発見品）に分ける。
- 状態：保存データを version 3 にする。持つものは、深度、図鑑（品ごとの所持数）、日ごとの統計（探索回数、ポイント、スクロール距離、部屋別の探索回数）、直近の出来事。旧データは引き継がない（開発中のデータのため）。
- 通信：採掘完了メッセージに部屋のIDを含める。抽選は service worker が、部屋と階層から行う。
- 画面：
  - ポップアップは、現在の階層、今日の探索回数、職業、図鑑・設定へのボタンにする。
  - 図鑑は、部屋ごとの構成に変える。職業診断、分布グラフ、発見率を足す。
  - 右端の帯は、深度、階層名、ゲージ、見つけた品の演出だけにする。背景は階層ごとの景色に変える。
- 用語：コードと画面の「鉱石（ore）」を「発見品（item）」に変える。
- Phase 4 以降：Firestore の `users/{uid}` に、公開設定（見せるかどうか、伏せる部屋）を足す。「自分で地上に戻った回数」は、仕様から外す。

## 10. 物色の演出と入れ物（追加仕様）

- スクロール中は、右端の帯で探索者が歩く。見た目は診断された職業に合わせて変わる（診断前は標準の見た目）。
- 止めて1秒後に、入れ物が1つ現れる。約4秒の物色のあと、品が見つかる。**1回の立ち止まりで見つかる品は1つだけ**。次にスクロールするまでは、開いた入れ物がそのまま残り、もう見つからない。
- 入れ物は壺（45%）・箱（40%）・宝箱（15%）。出る品のレア度の重みに、入れ物ごとの倍率を掛ける（壺 1.2/0.7/0.3、箱 1/1/1、宝箱 0.6/1.5/2.5）。平均すると、レア度の出方はほぼ変わらない。
- 宝箱は12%でミミック（全体で約1.8%）。ペナルティはなく、専用の戦利品（かじられた金貨・ミミックの牙・よだれまみれの鍵・擬態の宝石）が出る。階層の秘宝はミミックからは出ない。
- 見た目: 壺と宝箱とミミックは階層ごと、箱は部屋ごと（劇場=フィルムケース、酒場=樽、書庫=本棚、道具屋・宿場町・情報屋・闘技場・未踏の地=木箱、工房・音楽堂・ギルド=ケース）。
- 記録には、入れ物ごとの発見数も残る（CSVにも列が増える）。
