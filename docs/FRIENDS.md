# <img src="images/icons/feather.png" width="28" height="28" align="absmiddle" alt=""> フレンド機能の準備

[← README に戻る](../README.md)

Google ログインとフレンド機能には、自分の Firebase プロジェクトが必要です。ゲーム本体は、設定なしで遊べます。

拡張機能の ID は、manifest の `key` で固定してあり、どこで読み込んでも **`bbobbhlfhcagdknjegkibkekcbnaiagm`** です。

## 手順

1. **Firebase プロジェクトを作る。** [Firebase コンソール](https://console.firebase.google.com/)で「プロジェクトを追加」を選びます。料金プランは Spark（無料）のままにします。
2. **Authentication を有効にする。** 「構築」→「Authentication」→「始める」→「ログイン方法」で **Google** を有効にし、サポートメールを選んで保存します。
3. **Firestore を作る。** 「構築」→「Firestore Database」→「データベースを作成」。ロケーションは `asia-northeast1`（東京）、モードは**本番環境モード**です。
4. **セキュリティルールを公開する。** Firestore の「ルール」タブに、[`firestore/firestore.rules`](../firestore/firestore.rules) の中身をすべて貼って「公開」します。Firebase CLI なら `firebase deploy --only firestore:rules` です。
5. **ウェブアプリを登録する。** 「プロジェクトの設定」→「全般」→「マイアプリ」で「ウェブ」（`</>`）を追加し、表示される設定値を控えます。
6. **OAuth クライアント ID を作る。** [Google Cloud コンソール](https://console.cloud.google.com/)で、同じプロジェクトを選びます。
   - 「API とサービス」→「OAuth 同意画面」で、ユーザーの種類を「外部」にし、アプリ名・サポートメール・連絡先メールを入れます。スコープは `openid` `email` `profile` だけです。
   - 「認証情報」→「認証情報を作成」→「OAuth クライアント ID」で、種類を **「Chrome 拡張機能」** にし、アイテム ID に上の ID を入れます。作成後に出るクライアント ID を控えます。
7. **`.env` を作る。** `.env.example` を `.env` にコピーし、5 と 6 の値を書きます。`=` の前後に、スペースや引用符（`"`）は付けません。`.env` は Git に入りません。
8. **ビルドして読み込む。** `npm run build` のあと、拡張機能を更新します。ポップアップの「ランキング」から、ログインできます。

> [!IMPORTANT]
> OAuth 同意画面の公開ステータスが「テスト」のままだと、**登録したテストユーザーしかログインできません**。誰でも使えるようにするには「本番環境に公開」にします（このスコープなら、審査は不要です）。

> [!WARNING]
> ビルドした `dist/` には、5 の設定値（Firebase の API キーなど）と、6 のクライアント ID が入ります。公開されても問題ない値（守りは Firestore のルールが担います）ですが、`dist/` を GitHub にプッシュすると、公開されます。

> [!NOTE]
> セキュリティルールは、拡張機能の更新で変わることがあります。更新のあとも、最新の内容を貼り直してください。

## しくみ

- 8文字のフレンドコード（0・O・1・I は使いません）を相手に伝えて、申請してもらいます。
- 承認制です。お互いが承認してはじめて、フレンドになります。拒否・解除もできます。
- 自分の値は、変化があるとき 15 分ごとに、Firestore へ送ります。フレンド画面の「同期」で、すぐ送ることもできます。
- 送るのは、ニックネーム、フレンドコード、フレンド一覧、今週のポイントと発見数、Google アカウントのアイコン（画像の URL）です。図鑑・飾り棚・部屋の分布は、公開設定で「見せる」にしたときだけ送ります。
- 設計とルールの詳細は [PHASE4.md](PHASE4.md) を見てください。

## 困ったとき

| 症状 | 原因と対応 |
|---|---|
| 「このアプリは確認されていません」と出る | OAuth 同意画面の公開ステータスが「テスト」のままです。「本番環境に公開」にするか、テストユーザーに自分を追加してください |
| 「フレンド機能は利用不可」と出る | `.env` が未設定のままビルドされています。手順 7 と 8 をやり直してください |
| 「操作が拒否された（…）」と出る | Firestore のルールが、公開されていない、古い、または貼り付けが途中で切れています。ルールを全部貼り直して「公開」し、再ログインしてください。かっこの中は、拒否された操作です |
| フレンドのアイコンが、頭文字のままになる | 相手が、最新の拡張機能で同期するまでです。ルールが古いと、同期が拒否されます（上の行） |
