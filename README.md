# 迷宮スクロール（仮称）

スクロールで迷宮を降り、立ち止まって入れ物を物色すると、見ているサイトの種類にまつわる品が見つかる、Chrome 拡張機能のゲーム。

仕様は `docs/SPEC.md`。

## 開発

```
npm install
npm run build      # dist/ に拡張機能を出力
npm test           # 純粋関数の単体テスト（Vitest）
npm run dev        # 開発用（変更が自動で反映される。dist/ を読み込む）
```

## すぐに使う（ビルド不要）

ビルド済みの拡張機能が `dist/` に入っています。

1. このリポジトリを ZIP でダウンロードして展開する（GitHub の「Code」→「Download ZIP」）、または `git clone` する
2. Chrome で `chrome://extensions` を開き、右上の「デベロッパーモード」をオンにする
3. 「パッケージ化されていない拡張機能を読み込む」を押し、展開したフォルダの中の **`dist`** フォルダを選ぶ
4. 初回は説明画面が開く。内容を確認したら、ページをスクロールして遊ぶ

ソースを変えたときは `npm run build` で `dist/` を作り直し、拡張機能カードの更新ボタンを押して、開いているページを再読み込みします（`dist/` もコミットしておくこと）。

## フレンド機能の準備（使いたいときだけ）

ゲーム本体は、設定なしで遊べます。Googleログインとフレンド機能を使うには、Firebase の設定が必要です。拡張機能のIDは、manifest の `key` で固定してあり、**`bbobbhlfhcagdknjegkibkekcbnaiagm`** です（どこで読み込んでも同じ）。

1. **Firebase プロジェクトを作る:** [Firebase コンソール](https://console.firebase.google.com/) →「プロジェクトを追加」。料金プランは Spark（無料）のままにします。
2. **Authentication:** 左の「構築」→「Authentication」→「始める」→「ログイン方法」で **Google** を有効にし、プロジェクトのサポートメールを選んで保存します。
3. **Firestore:** 「構築」→「Firestore Database」→「データベースを作成」。ロケーションは `asia-northeast1`（東京）、モードは**本番環境モード**にします。
4. **セキュリティルール:** Firestore の「ルール」タブに、このリポジトリの `firestore.rules` の中身をすべて貼って「公開」します。（Firebase CLI を使う場合は `firebase deploy --only firestore:rules`）
5. **ウェブアプリを登録:** 「プロジェクトの設定」→「全般」→「マイアプリ」で「ウェブ」（`</>`）を追加し、表示される設定値を控えます。
6. **OAuth クライアントID:** [Google Cloud コンソール](https://console.cloud.google.com/)で、同じプロジェクトを選びます。
   - 「APIとサービス」→「OAuth 同意画面」: ユーザーの種類は「外部」。アプリ名・サポートメール・連絡先メールを入れます。スコープは `openid` `email` `profile` だけです。公開ステータスが「テスト」のままだと、**登録したテストユーザーしかログインできません**。誰でも使えるようにするには「本番環境に公開」にします（このスコープなら審査は不要です）。
   - 「認証情報」→「認証情報を作成」→「OAuth クライアントID」: アプリケーションの種類は **「Chrome 拡張機能」**、アイテムIDに上のID（`bbobbhlfhcagdknjegkibkekcbnaiagm`）を入れます。作成後に出るクライアントIDを控えます。
7. **`.env` を作る:** `.env.example` を `.env` にコピーし、5 と 6 の値を記入します（`.env` は Git に入りません）。
8. **ビルドして読み込む:** `npm run build` のあと、拡張機能を更新します。ポップアップの「フレンド」から、ログインできます。

> ビルドした `dist/` には、5 の設定値（Firebase の API キーなど）が入ります。これは公開されても問題ない値（守りは Firestore のルールが担います）ですが、`dist/` を GitHub にプッシュすると、その値も公開されます。

## うまくいかないとき

- **学校・会社のアカウントのプロファイルで、拡張機能のカードが消える（特に、PC を起動し直したあと）:** 管理者が、デベロッパーモードの拡張機能を許可しない設定（`ExtensionDeveloperModeSettings`）や、許可リスト以外をブロックする設定（`ExtensionInstallBlocklist`）にしている可能性があります。`chrome://policy` で確認できます。個人の Google アカウントのプロファイル（または、アカウントなしのプロファイル）に読み込むと、消えません。管理者に頼む場合は、拡張機能のID **`bbobbhlfhcagdknjegkibkekcbnaiagm`** の許可を依頼してください。
- **ログインで「このアプリは確認されていません」と出る:** OAuth 同意画面の公開ステータスが「テスト」のままです。「本番環境に公開」にするか、テストユーザーに自分を追加してください。

## 遊び方（ダンジョン探索版）

操作や管理は要りません。いつもどおりページを読むだけです。

- 下にスクロールすると、迷宮を降ります（深度が増え、深さで「階層」が変わります）。
- 帯の長さは、ページの長さに対応します。探索者は、ページを読み進めるほど、帯の上から下へ降りていきます。品を見つけた場所には、開けた入れ物の目印が残ります（そのページを開いている間だけで、保存しません）。
- 右端の帯の背景は、見ているサイトの種類（部屋）ごとに変わります（劇場=赤いカーテン、酒場=木の壁とジョッキ、書庫=本棚、道具屋=日よけの縞、工房=回路のタイル など）。階層は、壁にかぶせる色で表します。
- スクロール中は、右端の帯で探索者（職業に合わせた見た目）が歩きます。止めて1秒たつと入れ物が現れ、約4秒の物色のあと、中の品が見つかります。
- 入れ物は壺・箱・宝箱のどれかで、宝箱は★3が出やすく、壺は★1が出やすくなります。まれに宝箱がミミックで、専用の戦利品が手に入ります。壺と宝箱の見た目は階層ごと、箱の見た目は部屋（サイトの種類）ごとに変わります。
- **1回の立ち止まりで見つかる品は1つだけ**です。もう一度スクロールしてから止まると、次の入れ物が現れます。
- 見つけた品は、そのまま図鑑に入ります（★1=1点、★2=3点、★3=10点）。
- サイトの種類（劇場・酒場・書庫・道具屋・工房・闘技場・音楽堂・宿場町・ギルド・未踏の地）で、見つかる品が変わります。種類はホスト名を端末の中で判定するだけで、ホスト名・URLは保存も送信もしません。
- 各階層に1つ、まれに見つかる「階層の秘宝」があります。
- ポップアップからは図鑑を開けます。図鑑には、職業診断（見つけた品の部屋の割合）、飾り棚（3つまで）、記録（日ごと・週ごと、グラフ、CSV書き出し）があります。
- 初めてインストールしたときは、何を記録するかの説明画面が開きます。
- 企画の詳細は `docs/CONCEPT-DUNGEON.md` を参照。

## ドット絵の作り直し

ドット絵は Python 3 のツールで作ります。絵を変えたら実行し直すと、`src/data/` の JSON が更新されます。

- `python tools/make-sprites.py`: 発見品のアイコン（`sprites.json`）
- `python tools/make-actors.py`: 入れ物と職業別の探索者（`actors.json`）
- 共通の部品と色の表は `tools/art.py`

## デバッグ表示のオン・オフ

拡張機能カードの「service worker」を開いて DevTools のコンソールに入力する。

```js
chrome.storage.local.set({ settings: { debugOverlay: false } })  // オフ
chrome.storage.local.set({ settings: { debugOverlay: true } })   // オン
chrome.storage.local.set({ settings: { effects: false } })       // 右端の演出をオフ
chrome.storage.local.set({ settings: { reserveSpace: false } })  // ページの右に余白を取らず、帯を重ねる
```

## 保存データの確認・リセット

service worker のコンソールで:

```js
(await chrome.storage.local.get('state')).state   // 確認
chrome.storage.local.clear()                      // 全消去
```
