# 迷宮スクロール（仮称）

いつものブラウジングに「プラスα」を足す、Chrome 拡張機能のゲームです。ページを下へスクロールすると迷宮を降り、立ち止まると入れ物（壺・箱・宝箱）が現れて、いま見ているサイトの種類にまつわる品が見つかります。操作や管理は要りません。

- ページを読むだけで遊べます（ログイン不要）。
- 見ているサイトの種類（動画、SNS、ニュース、学習、買い物…）で、見つかる品が変わります。
- 見つけた品は図鑑にたまり、集めた傾向から「職業」が診断されます。
- ログインすると、フレンドと今週のポイントを比べられます（使いたい人だけ）。
- 見たページのURL・タイトル・本文は、記録も送信もしません。

## 1. すぐに使う

ビルド済みの拡張機能が `dist/` に入っているので、ダウンロードしてすぐ使えます。

1. このリポジトリを ZIP でダウンロードして展開します（GitHub の「Code」→「Download ZIP」）。`git clone` でも構いません。
2. Chrome で `chrome://extensions` を開き、右上の「デベロッパーモード」をオンにします。
3. 「パッケージ化されていない拡張機能を読み込む」を押して、展開したフォルダの中の **`dist`** フォルダを選びます。
4. 初回は、何を記録するかの説明画面が開きます。内容を確認して、ページをスクロールして遊びます。

> 学校・会社などの管理されたアカウントでは、拡張機能が使えない場合があります。個人のアカウントのプロファイルで使ってください（[うまくいかないとき](#7-うまくいかないとき)）。

## 2. 遊び方

### 基本の流れ

1. **下にスクロールする。** 迷宮を降りて、深さが増えます（1000px のスクロールで約 26m）。
2. **止める。** 止めて1秒たつと、入れ物が1つ現れます。
3. **物色する。** 探索者が約4秒、入れ物をあさります。
4. **品が見つかる。** 見つけた品は、そのまま図鑑に入ります。

**1回の立ち止まりで見つかる品は1つだけ**です。立ち止まり続けても増えません。もう一度スクロールしてから止まると、次の入れ物が現れます。1日の発見数の上限は 300 個です。

### 見つかる品

| 種類 | 数 | 内容 |
|---|---|---|
| 部屋の品 | 66 | サイトの種類（部屋）ごとに6種（★1を3、★2を2、★3を1）。11の部屋があります |
| 階層の秘宝 | 6 | 階層ごとに1つ。どの部屋でも、まれに見つかります（約3%） |
| ミミックの戦利品 | 4 | 宝箱に化けた魔物から、まれに手に入ります |

ポイントは、★1 = 1点、★2 = 3点、★3 = 10点です。

**サイトの種類（部屋）**

| 部屋 | サイト | 職業 |
|---|---|---|
| 劇場 | 動画・配信 | 踊り子 |
| 酒場 | SNS・掲示板 | 遊び人 |
| 情報屋 | ニュース・ブログ | 斥候 |
| 書庫 | 辞書・学習・技術文書 | 賢者 |
| 道具屋 | 買い物 | 商人 |
| 工房 | コード・開発者向け | 錬金術師 |
| 闘技場 | ゲーム・攻略 | 戦士 |
| 音楽堂 | 音楽 | 吟遊詩人 |
| 宿場町 | 地図・旅行・乗換案内 | 旅人 |
| ギルド | メール・カレンダー・仕事 | 騎士 |
| 未踏の地 | 上のどれでもないサイト | 放浪者 |

どの部屋にも偏らないときの職業は「勇者」です。ある部屋が全体の4割以上を占めると、その部屋の職業になります（見つけた品が5個たまってから診断します）。

### 入れ物

| 入れ物 | 出る確率 | 特徴 |
|---|---|---|
| 壺 | 45% | ★1が出やすい |
| 箱 | 40% | ふつう |
| 宝箱 | 15% | ★3が出やすい。12%はミミック |

- **壺・宝箱・ミミック**の見た目は、階層ごとに変わります。**箱**の見た目は、部屋（サイトの種類）ごとに変わります（劇場はフィルムケース、酒場は樽、書庫は本棚、など）。
- 階層は、深さ 0・50・150・400・800・1500m で変わります。深い階層ほど、★2・★3が出やすくなります。
- 入れ物ごとの倍率は、全体で見ると、レア度の出方がほぼ変わらないように決めてあります。

### 右端の帯

画面の右端（スクロールバーのすぐ左）に、細い帯が出ます。

- **探索者:** 診断された職業に合わせた見た目で、ページを読み進めるほど、帯の上から下へ降ります。スクロール中は歩き、止まると入れ物をあさります。
- **ゲージ:** 6つの目盛りが、物色の進みに合わせて点きます。
- **壁:** サイトの種類で絵が変わります（劇場は赤いカーテン、書庫は本棚、工房は回路のタイル、など）。
- **深さに応じた変化:** スクロールに合わせて、壁の色合いと飾りが、リアルタイムで少しずつ変わります。深さ 100m ごとに、土と根 → 水と苔 → 坑道の梁 → 水晶 → 溶岩 → 深い闇の順に移り、600m で最初に戻ります。
- **目印:** 品を見つけた場所に、開けた入れ物の小さな目印が残ります。深く進むと壁といっしょに上へ流れ、帯から出ると消えます。メモリだけで、保存しません。
- **ページの右の余白:** 帯と重ならないよう、ページの右に、帯の幅ぶんの余白を取ります（設定でオフにできます）。

OS の「視覚効果を減らす」設定がオンのときは、色を混ぜずに、200m ごとに切り替えます。

## 3. 画面

ツールバーの拡張機能アイコンを押すと、ポップアップが開きます。

| 画面 | 内容 |
|---|---|
| **ポップアップ** | 深さ、職業、最近の発見、図鑑・ランキング・設定へのボタン、「このサイトでは、ゲームを動かさない」の切り替え、帯の表示の切り替え |
| **図鑑** | 「アイテム図鑑」（部屋ごとの一覧と、職業診断、部屋の分布）、「飾り棚」（お気に入りを3つまで）、「記録」（日ごと・週ごとのグラフと表、CSV書き出し） |
| **ランキング** | 自分とフレンドの今週のポイント。フレンドを選ぶと、公開されている内容が見られます。「フレンド・アカウント」のタブで、申請・承認・解除・ニックネームの変更・公開範囲の設定・アカウントの削除ができます（[フレンド機能の準備](#6-フレンド機能の準備使いたいときだけ)が必要） |
| **設定** | ゲームを動かさないサイト、デモモード、帯の表示、デバッグ表示 |

ランキングの順位は、**今週のポイントの合計**だけで決まります（週は月曜0時はじまり）。深さやスクロールの量では、順位をつけません。

## 4. プライバシー

- **記録しないもの:** 見たページのURL、サイト名（ホスト名）、タイトル、本文、入力した内容。
- **サイトの種類の判定:** ページを開いている間だけ、拡張機能の中で、ホスト名を辞書と照合します。残すのは「種類」だけです。成人向け・医療・金融などのサイトは、辞書に載せず、「未踏の地」になります。ローカルや社内のホスト、IP アドレスも同じです。
- **この端末に保存するもの:** 深さ、図鑑、飾り棚、日ごとの集計（回数・ポイント・距離・部屋ごとの発見数・入れ物ごとの発見数）、設定。
- **フレンド機能を使うときに、Firebase に送るもの:**
  - 常に: ニックネーム、フレンドコード、フレンドの一覧、今週のポイントと発見数
  - 公開設定を「見せる」にしたときだけ: 図鑑（発見品ごとの所持数）、飾り棚、部屋ごとの発見数（職業の元）。「見せない部屋」を選ぶと、その部屋の分は送りません。
  - 初期設定は、すべて「見せない」です。
- Googleアカウントの本名・メールアドレス・アイコンは、他の人には見えません。

## 5. 設定

ポップアップの「設定」から開きます。

### ゲームを動かさないサイト

登録したサイトでは、帯を出さず、スクロールも数えず、品も見つかりません。サブドメインも含みます（`example.com` を登録すると、`www.example.com` も無効）。ポップアップの「このサイトでは、ゲームを動かさない」からも登録できます。この一覧は、この端末にだけ保存し、外には送りません。

### デモモード

発表で、短い時間に見せるためのモードです。

- 深さが 20 倍の速さで進みます（階層や背景が、すぐ変わります）。
- 物色が 2 秒になります。
- 宝箱とミミックが出やすくなります。
- 帯の上に「DEMO」と出ます。

**デモ中の記録は、本番のデータとは別に保存します。** 本番の図鑑・ポイントは増えず、ランキングにも送りません。「デモのデータを消して、最初から」で、やり直せます。ランキングとフレンドの画面は、デモ中でも、本番のデータです。

### 表示

帯の表示、ページの右の余白、デバッグ表示（開発用。条件の成否などを、右下に出します）を切り替えられます。

## 6. フレンド機能の準備（使いたいときだけ）

ゲーム本体は、設定なしで遊べます。Google ログインとフレンド機能を使うには、Firebase の設定が必要です。拡張機能の ID は、manifest の `key` で固定してあり、**`bbobbhlfhcagdknjegkibkekcbnaiagm`** です（どこで読み込んでも同じ）。

1. **Firebase プロジェクトを作る:** [Firebase コンソール](https://console.firebase.google.com/) →「プロジェクトを追加」。料金プランは Spark（無料）のままにします。
2. **Authentication:** 左の「構築」→「Authentication」→「始める」→「ログイン方法」で **Google** を有効にし、プロジェクトのサポートメールを選んで保存します。
3. **Firestore:** 「構築」→「Firestore Database」→「データベースを作成」。ロケーションは `asia-northeast1`（東京）、モードは**本番環境モード**にします。
4. **セキュリティルール:** Firestore の「ルール」タブに、このリポジトリの `firestore.rules` の中身をすべて貼って「公開」します（Firebase CLI なら `firebase deploy --only firestore:rules`）。
5. **ウェブアプリを登録:** 「プロジェクトの設定」→「全般」→「マイアプリ」で「ウェブ」（`</>`）を追加し、表示される設定値を控えます。
6. **OAuth クライアント ID:** [Google Cloud コンソール](https://console.cloud.google.com/)で、同じプロジェクトを選びます。
   - 「API とサービス」→「OAuth 同意画面」: ユーザーの種類は「外部」。アプリ名・サポートメール・連絡先メールを入れます。スコープは `openid` `email` `profile` だけです。公開ステータスが「テスト」のままだと、**登録したテストユーザーしかログインできません**。誰でも使えるようにするには「本番環境に公開」にします（このスコープなら審査は不要です）。
   - 「認証情報」→「認証情報を作成」→「OAuth クライアント ID」: アプリケーションの種類は **「Chrome 拡張機能」**、アイテム ID に上の ID を入れます。作成後に出るクライアント ID を控えます。
7. **`.env` を作る:** `.env.example` を `.env` にコピーし、5 と 6 の値を記入します。`=` の前後にスペースや引用符（`"`）は付けません。`.env` は Git に入りません。
8. **ビルドして読み込む:** `npm run build` のあと、拡張機能を更新します。ポップアップの「ランキング」から、ログインできます。

> ビルドした `dist/` には、5 の設定値（Firebase の API キーなど）と、6 のクライアント ID が入ります。これらは公開されても問題ない値（守りは Firestore のルールが担います）ですが、`dist/` を GitHub にプッシュすると、公開されます。

### フレンドのしくみ

- 8文字のフレンドコード（0・O・1・I は使いません）を相手に伝えて、申請してもらいます。
- 承認制です。お互いが承認してはじめて、フレンドになります。拒否・解除もできます。
- フレンドの値は、相手の端末から、変化があるとき 15 分ごとに、Firestore へ届きます。
- 設計とルールの詳細は [`docs/PHASE4.md`](docs/PHASE4.md) を参照してください。

## 7. うまくいかないとき

| 症状 | 原因と対応 |
|---|---|
| 学校・会社のアカウントで、拡張機能のカードが消える（特に PC を起動し直したあと） | 管理者が、デベロッパーモードの拡張機能を許可しない設定（`ExtensionDeveloperModeSettings`）や、許可リスト以外をブロックする設定（`ExtensionInstallBlocklist`）にしている可能性があります。個人の Google アカウントのプロファイル（またはアカウントなしのプロファイル）に読み込むと、消えません。管理者に頼む場合は、拡張機能の ID の許可を依頼してください |
| ログインで「このアプリは確認されていません」と出る | OAuth 同意画面の公開ステータスが「テスト」のままです。「本番環境に公開」にするか、テストユーザーに自分を追加してください |
| フレンド画面に「まだ使えません」と出る | `.env` が未設定のままビルドされています。[フレンド機能の準備](#6-フレンド機能の準備使いたいときだけ)を行って、ビルドし直してください |
| ログインのあとに「許可されていません」と出る | Firestore のルールが、公開されていない、または貼り付けが途中で切れています |
| 品が見つからない | そのサイトが「ゲームを動かさないサイト」に登録されていないか、1日の上限（300個）に届いていないかを確認してください。ページを開いたまま拡張機能を更新したときは、ページを再読み込みしてください |
| 帯が、サイトの表示と重なる | 設定で、「ページの右に余白を取る」がオンになっているか確認してください |

## 8. 開発者向け

### セットアップ

```
npm install
npm run build      # 型チェックのあと、dist/ に拡張機能を出力
npm test           # 単体テスト（Vitest）
npm run dev        # 開発用（変更が自動で反映される。dist/ を読み込む）
```

ビルドのあとは、`chrome://extensions` で拡張機能の更新ボタンを押し、開いているページを再読み込みします。`dist/` は、ダウンロードしてすぐ使えるように、コミットしています（ソースを変えたら、ビルドして、一緒にコミットしてください）。

### 構成

| 場所 | 内容 |
|---|---|
| `src/core/` | 判定や計算の純粋な関数（深さ、抽選、入れ物、職業、ランキング、サイトの種類の判定など）。すべてテストがあります |
| `src/content/` | ページに挿入されるコード（スクロールの計測、物色の進行、右端の帯） |
| `src/background/` | service worker（状態の更新、15 分ごとの同期） |
| `src/popup/` `src/collection/` `src/friends/` `src/settings/` `src/welcome/` | 拡張機能の画面（React） |
| `src/firebase/` | ログイン、フレンド、同期（Firebase） |
| `src/data/` | 階層（`areas.json`）、部屋とサイトの辞書（`genres.json`）、発見品（`items.json`）、ドット絵（`sprites.json`、`actors.json`） |
| `src/config.ts` | 調整できる数値のすべて（下記） |
| `tools/` | 生成ツール |
| `firestore.rules` | セキュリティルール（自動生成） |
| `docs/` | 仕様・企画・設計のメモ |

### 調整できる値（`src/config.ts`）

| 値 | 意味 | 現在 |
|---|---|---|
| `DEPTH_MULTIPLIER` | 実際の距離(m)に掛ける倍率 | 100 |
| `FIND_START_DELAY_SEC` / `FIND_DURATION_SEC` | 止まってから入れ物が現れるまで / 物色の長さ | 1秒 / 4秒 |
| `MAX_FINDS_PER_DAY` | 1日の発見数の上限 | 300 |
| `RARITY_POINTS` | ★ごとのポイント | 1 / 3 / 10 |
| `CONTAINER_WEIGHTS` / `CONTAINER_RARITY_MULT` / `MIMIC_IN_CHEST` | 入れ物の出やすさ / レア度の倍率 / ミミックの確率 | 45・40・15 / 表のとおり / 12% |
| `SYNC_INTERVAL_MIN` | 同期の間隔 | 15分 |
| `OVERLAY_WIDTH_PX` | 帯の幅 | 56px |

デモモードの値は、同じファイルの `DEMO_OVERRIDES` にあります。背景が移り変わる間隔は、`src/core/band.ts` の `BAND_STEP_M`（100m）です。

### 生成ツール

```
python tools/make-sprites.py   # 発見品のアイコン → src/data/sprites.json
python tools/make-actors.py    # 入れ物と職業別の探索者 → src/data/actors.json
python tools/make-hero-sheet.py # 全職業の見た目の一覧 → hero-sheet.png（Pillow が必要）
python tools/make-icons.py     # 拡張機能のアイコン → src/icons/（Pillow が必要）
node tools/make-rules.mjs      # セキュリティルール → firestore.rules
```

- 発見品や部屋を増やしたら、`firestore.rules` を作り直して、Firebase にも貼り直してください（`tests/rules.test.ts` が、最新かどうかを確かめます）。
- ドット絵の共通の部品と、色の表は `tools/art.py` です。

### デバッグ

設定ページで「デバッグ表示」をオンにすると、右下に、条件の成否や場面が出ます。保存データは、拡張機能カードの「service worker」を開いて、DevTools のコンソールで確認できます。

```js
(await chrome.storage.local.get('state')).state   // 本番のデータ
(await chrome.storage.local.get('demoState')).demoState   // デモのデータ
chrome.storage.local.clear()                      // 全消去
```

### 保存データのキー

`state`（本番の状態）、`demoState`（デモの状態）、`profile` / `demoProfile`（飾り棚と初回確認）、`settings`、`account`（ログイン中のアカウントの控え）、`sync`（最後に送った内容）。
